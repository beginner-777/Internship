# A Night Written in Stars

Premium React + Vite birthday surprise website with an interactive moon,
constellation text, canvas fireworks, line-by-line birthday wishes, music, and
a final wish animation.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this folder or its Git repository in Vercel. The included `vercel.json`
uses `npm run build` and deploys the generated `dist` directory.

No environment variables are required.
