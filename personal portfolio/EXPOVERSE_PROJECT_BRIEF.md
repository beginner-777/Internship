# EXPOVERSE — Project Brief

## Product

EXPOVERSE is an interactive 3D virtual fashion showroom for businesses. It will allow visitors to explore clothing and accessories collections, inspect featured products, open information hotspots, save favourites, compare items, and request a quotation or private appointment.

## Portfolio purpose

The project will demonstrate creative 3D frontend engineering for a real business use case. It will use realistic demo data so the primary effort remains focused on environment design, interaction quality, responsive behaviour, accessibility, and performance.

## Mandatory colour approval gate

No colour palette has been selected in advance. Before implementation begins, five genuinely different image-based showroom concepts must be presented using the same scene and layout. Each image must demonstrate its palette across the environment, lighting, navigation, product hotspot, product card, typography, and controls, with labelled HEX values. Implementation begins only after one concept or a requested combination is approved.

## Case-study story

- **Problem:** Conventional product grids often fail to communicate the atmosphere and premium presentation fashion businesses want online.
- **What I will do:** Design and build a realistic 3D showroom with product hotspots, collection navigation, catalogue fallbacks, responsive controls, keyboard access, reduced motion, and adaptive scene quality.
- **Expected outcome:** A polished, deployable fashion showroom experience with verified routes, performance decisions, accessibility support, and a documented production workflow.

## Planned stack

- Next.js App Router
- Strict TypeScript
- Tailwind CSS
- React Three Fiber, Three.js, and Drei
- Framer Motion
- React Hook Form and Zod
- Vitest, React Testing Library, Playwright, and axe

## Planned content

- Signature Apparel
- Handbags and Leather Goods
- Footwear
- Watches and Jewellery
- Limited Edition Accessories

## Definition of done

The finished project must have meaningful content, working navigation, no blank routes, reliable refresh and browser-back behaviour, responsive layouts, a non-WebGL fallback, accessible interaction alternatives, validated forms, tests, documentation, a successful production build, and a verified live deployment.
